# Decisiones UI actuales

Estas decisiones fueron confirmadas para la interfaz y deben mantenerse:

- El sidebar no muestra la sección Notificaciones.
- El orden operativo es: Listos para dispensar, Puntos de aplicación, Órdenes de compra, Logística OLP, Soportes y Auditoría.
- La numeración visual de los ítems del sidebar es única y secuencial.
- `/cargas` muestra Validaciones principales como una franja horizontal debajo del título y la descripción de Carga de autorizaciones.
- Administración no muestra usuarios/roles de ejemplo.
- Administración no muestra Destinatarios de notificaciones, Reporte diario ni Integraciones.
- Administración conserva únicamente la configuración de Google Drive mientras no exista un endpoint funcional para ella.
- Las cargas y exportaciones funcionales usan exclusivamente XLSX (`.xlsx`).
- Los encabezados del Anexo Tarifario son `CODIGO_MEDICAMENTO`, `TARIFA_UNIDAD`, `NUMERO_EXPEDIENTE_INVIMA`, `CONSECUTIVO_INVIMA_PRESENTACION`, `DESCRIPCION_GENERICA_MEDICAMENTO`, `DESCRIPCION_COMERCIAL_MEDICAMENTO`, `LABORATORIO_MEDICAMENTO`, `TIPO_INCLUSION_MEDICAMENTO`.
