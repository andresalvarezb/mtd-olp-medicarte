# ADR-011 — Monorepo TypeScript

**Estado:** ACCEPTED

## Decisión

Cuando el destino físico se confirme, mantener `web`, `api`, `worker` y paquetes compartidos bajo pnpm/Turborepo si se usa el monorepo propuesto.

## Nota

DEC-010 y ADR-019 fijan un repositorio GitHub independiente; esta decisión no justifica duplicar contratos ni reglas.
